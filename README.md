# TaskDo — список дел с синхронизацией

Приложение для ведения списка задач с возможностью синхронизации через общий сервер. Доступно в версиях: **десктоп (Python)** и **мобильное (Android)**.

## Возможности

- Добавление и удаление задач с автоматической отметкой времени
- Подсчёт действий за сегодня и за всё время
- Синхронизация между устройствами через HTTP‑сервер (Flask)
- Поддержка тёмной/светлой темы (десктоп и Android)
- Автоматическая синхронизация (для десктопа)
- Офлайн‑хранение задач в локальном файле

## Состав репозитория

- `gui.py` – десктопное приложение на Python (tkinter)
- `server.py` – TCP‑сервер для синхронизации десктопных клиентов
- `web_server.py` – HTTP‑сервер на Flask (REST API) для мобильных клиентов
- `index.html` – веб‑интерфейс для доступа с любого устройства
- `android/` – исходный код мобильного приложения на Kotlin
- `tasks.json` – локальный файл с задачами (синхронизируется)

## Десктопная версия (Python)

### Требования
- Python 3.8+
- Установленные зависимости: `tkinter` (встроен), `socket`, `json`, `os` (стандартные)
