# TaskDo Mobile

Мобильное приложение для ведения списка дел с синхронизацией через сервер. Является клиентом к ранее разработанной системе (десктопное приложение на Python и HTTP‑сервер).

## Возможности

- Добавление и удаление задач
- Отображение счётчиков: действий сегодня и всего
- Синхронизация с сервером по HTTP (REST API)
- Автоматическое обновление списка
- Тёмная/светлая тема (в зависимости от системных настроек)

## Требования

- Android 5.0 (API 21) и выше
- Серверная часть (см. ниже)

## Настройка сервера

1. Убедитесь, что у вас установлен Python 3.8+.
2. Скопируйте файлы `web_server.py` и `index.html` из репозитория (или из [основного репозитория](ссылка)).
3. Запустите сервер:
   ```bash
   python web_server.py
